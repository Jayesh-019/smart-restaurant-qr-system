# Smart Restaurant QR System

A premium QR-based restaurant ordering platform built with FastAPI, PostgreSQL, SQLAlchemy, and a modern Bootstrap frontend.

## Highlights

- QR table ordering
- Menu browsing without customer login
- Cart, order, and live status tracking
- Kitchen dashboard for live orders
- Cashier billing and payment handling
- Admin menu management and QR generation
- JWT-based staff authentication
- PostgreSQL-backed data storage

## Tech Stack

- Backend: Python, FastAPI, SQLAlchemy, Pydantic, JWT, Uvicorn
- Database: PostgreSQL
- Frontend: HTML, CSS, JavaScript, Bootstrap, jQuery
